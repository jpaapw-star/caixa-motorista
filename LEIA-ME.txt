CAIXA DO MOTORISTA — COMO COLOCAR O APP NO AR DE GRAÇA
======================================================

O que vem nesta pasta
---------------------
index.html ............ o app
local.js .............. guarda os dados no próprio celular
sw.js ................. faz o app abrir sem internet
manifest.webmanifest .. nome, cores e ícones (é o que deixa instalar)
icon-*.png ............ ícones
apple-touch-icon.png .. ícone do iPhone

Custo: zero. Não precisa de cartão, servidor nem loja de apps.


1. Crie uma conta grátis no GitHub
----------------------------------
Entre em https://github.com/signup e crie a conta.
O nome de usuário aparece no endereço do app.
Exemplo: usuário "joaomotorista" -> https://joaomotorista.github.io/caixa-motorista/


2. Crie um repositório
----------------------
Clique em "New repository" (ou no + lá em cima -> New repository).
- Repository name: caixa-motorista
- Deixe "Public" marcado (o GitHub Pages grátis exige repositório público;
  o código fica visível, mas os SEUS DADOS NÃO, porque eles ficam só no seu celular)
- Clique em "Create repository"


3. Envie os arquivos
--------------------
Na página do repositório, clique em "uploading an existing file".
Arraste TODOS os arquivos desta pasta (não a pasta, os arquivos de dentro).
Clique em "Commit changes".


4. Ligue o GitHub Pages
-----------------------
No repositório: Settings -> Pages.
Em "Build and deployment" -> Source: "Deploy from a branch".
Branch: "main", pasta "/ (root)". Clique em Save.
Espere 1 a 2 minutos. O endereço aparece no topo dessa mesma página.


5. Instale no celular
---------------------
Android (Chrome): abra o endereço -> menu (3 pontinhos) -> "Instalar app"
                  (ou "Adicionar à tela inicial").
iPhone (Safari):  abra o endereço -> botão Compartilhar -> "Adicionar à Tela de Início".

Pronto: o ícone aparece junto com os outros apps e abre em tela cheia, até sem internet.


Seus dados
----------
- Ficam só no celular onde você usa o app. Ninguém mais vê, nem o GitHub.
- Faça uma cópia de segurança de vez em quando:
  aba Resumo -> "Seus dados" -> "Salvar cópia". Guarde o arquivo no Drive, no e-mail ou no WhatsApp.
  O app avisa na tela inicial quando faz mais de 30 dias sem cópia.
- Trocou de celular ou limpou o navegador? Instale o app de novo e use "Restaurar cópia".
- Já anotou coisas no protótipo dentro do Claude? Lá, no Resumo, toque em "Salvar cópia".
  Depois, no app instalado, use "Restaurar cópia" com esse arquivo.
- Não abra o app numa aba anônima: ela apaga tudo ao fechar.


Atualizar o app depois
----------------------
Quando tiver uma versão nova, envie os arquivos novos para o mesmo repositório
(Add file -> Upload files, substituindo os antigos). Os dados no celular continuam lá.
O celular pega a versão nova na próxima vez que abrir o app com internet.


O que é diferente do protótipo no Claude
----------------------------------------
- A leitura de print/cupom com IA não existe aqui (ela usa o Claude). O resto é igual.
- Os dados ficam no celular, e não na sua conta do Claude.
